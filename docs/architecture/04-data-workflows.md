# 数据工作流

## 前端工作范围与导航恢复

主页面为开始、学习要求、已有表现、学习建议、案例与交付。学习要求、已有表现和学习建议共享已校验的运行/指标/学生/节点范围；案例学生槽位和班级报告节点是独立的交付范围，分别使用 `caseId` 与 `reportNodeId` URL 参数保存。恢复案例选择前必须确认 URL 的 `runId` 与当前运行相同，并逐一验证学生/节点属于当前快照。URL 不存答案正文、教师未保存文本或模型内容。

学生分析页的“形成学习建议”将当前学生、指标和节点带入 `/recommendations`。有有效评分时作为建议核对路径；没有有效评分时显示为补充观察路径。页面继续区分待评分、未作答、排除和隔离记录，缺少有效评分不会自动转成未掌握结论。

来源签核、教师复核、案例确认和教学调整保存后，通过共同数据变更通知使案例报告和发布预检重新读取；报告只读指定案例引用的复核版本，不能拼接当前最新方案。ready_with_open_checks 表示仍有未核验事项，与 blocked 和 ready 明确区分。

## 导入和运行

1. 前端 `ImportPanel` 把本机目录发往 `POST /api/import`。
2. Import 路由调用 `ImportFolder` Use Case；CSV Reader 校验六类文件、UTF-8 编码、表头和源行号。
3. 现有确定性分析服务检查事件修订、关联、评分范围、质量 findings，生成 metrics/observations/source index。
4. SourceService 计算允许来源文件元数据；导入 Use Case/Service 生成兼容 run_id，AnalysisRunRepository 在单个 SQLite UnitOfWork 中保存运行元数据、完整快照、关系投影及 `app_state.current_run_id`。
5. 返回 `run_id` 和质量报告。导入失败不会切换当前运行。

## 建议与教师复核

1. 前端选择学生和指标，请求规则草稿或 DeepSeek 草稿。
2. 规则服务从当前快照生成诊断。模型模式将允许证据传至可选 DeepSeek 客户端；模型输出须通过结构和证据 ID 校验。
3. 前端展示草稿，用户核对作答证据后提交复核。
4. `SaveReview` Use Case 在单个 `BEGIN IMMEDIATE` UnitOfWork 中检查学生、指标、引用范围和最新历史，再由 ReviewRepository 追加新版本；已有历史不覆盖。
5. 模型超时或供应方响应结构异常时，API 返回不含供应方细节的 502；前端仍可显式请求规则草稿，不自动接受或静默覆盖草稿。

## TASK 01–03 AI 证据分析与直接呈现

1. 用户在学习要求、班级比较、学生分析或学习建议页面选择当前任务范围。页面先读取该范围的供应商/模型、证据包数、记录数和指标数；生成前显示实际数据类别并要求单次显式确认。
2. Use Case 从已保存运行构造任务专属、分块证据包。确定性评分和统计仍由现有服务生成；AI 只接收去标识化文本、统计事实、质量处置与有条件的已核验课程标准 PDF 文本页。没有 OCR；不可读、未核验或超出 allowlist 的来源不会传给模型。
3. 现有 LLM 端口按包请求结构化解释。验证层拒绝未知字段、伪造编号、范围外引用和无法在本次输入中逐字定位的摘录，然后在本机恢复引用到真实运行记录。
4. 每个任务/范围的分析版本写入 `ai_analyses`，并绑定运行输入、来源核验、PDF 指纹、提示词和模型指纹。重复请求可复用最新结果；数据变化标记过期，局部失败保留已成功包并允许只重试失败包。
5. 前端按当前范围加载并直接展示结论、支持程度、限制、下一步建议、模型版本、覆盖计数及引用链接；查看 AI 结果不经过教师评价或批准。引用的作答记录可跳转到原始证据页，来源 PDF 引用可打开 allowlist 文件。已有教师复核/来源签核/导出流程不由 AI 分析自动写入或批准。

## 导出

1. `/api/export` 验证三个不同且有效的案例学生。
2. Export Service 读取当前分析快照和复核版本，生成统计、证据、原始作答、候选、已复核/待复核建议及字段说明。
3. 返回内存中的 ZIP 字节流；不将 ZIP 写入仓库。
4. 「案例与交付」由五个页面级组件组织；使用同一组当前运行内的三名案例学生供报告和 ZIP 入口使用。班级报告节点与分析节点分开，前者同时用于正式预检。更换案例/节点或保存来源、复核、案例、教学调整后，使相关报告与预检失效并重新读取。
5. 正式包依赖 `/api/release-checks` 返回的当前范围及指纹。前端在报告、节点或签核状态更新时禁用下载，直至当前预检通过；服务端在 `/api/export-submission` 再次校验。两个报告分别打印。

## 安全数据流

浏览器只向本地 API 发送目录路径和业务 ID，不读取本地文件、不持有模型密钥。来源 API 对 PDF 文件名做 allowlist 校验。AI 分析只在用户确认后调用兼容模型服务，并在服务端去标识化后传递本次任务所需的材料；学生作答文本仍可能包含个人信息，使用外部服务前应检查其数据处理约定。默认导入和统计不会触发模型调用。
