## 本轮修订

- 测验节点按模拟测验日期排序；缺失、无效或相同日期会明确标为顺序未确认。跨节点教学复测在日期不可判定时拒绝推断先后。
- 班级工作台的有效评分和原始作答数量限定到当前班级与测验节点；整体数据质量面板明确按当前运行统计。
- 班级复测以相同班级、同一观察指标、共同材料的有效评分记录计算比例，保留样本数、学生覆盖数和不可比较原因。教师观察仍作为教师判断展示，不表述为已证实因果效果。
- 学生教学调整的后续证据仅接受当前有效评分记录；待评分、已被修订替代和数据校验排除的记录会被后端拒绝，前端也不能新选无效记录。
- 学生级教学调整拒绝复用起始测验节点作为后续测验，即使选择的是同一运行中的有效评分；只有日期明确且晚于起始节点的测验可用作后续证据。
- 班级级教学调整同样拒绝复用实施节点作为复测节点；前端禁用起始节点、只显示后续节点的证据，后端对同节点请求返回校验错误，避免把同一轮作答记录成复测。
- 案例候选只有在单节点，或多节点均有有效日期且最新日期唯一时才确定当前节点；存在无效/缺失日期或最新日期并列时不生成当前案例候选。知识关系候选不再用节点编号猜跨主题先后；日期顺序有歧义时抑制跨主题候选，保留课程要求明确给出的同主题顺序。
- 首页与班级诊断在候选因节点日期歧义而被抑制时提示核对日期并重新导入，避免把空候选误读成“没有需要关注的案例”。
- 学生调整编辑器成功 PATCH 后曾因列表 key 包含 `updated_at` 而重挂载，清空成功状态。改为稳定的调整记录 ID key，并在正向 E2E 中验证保存提示和刷新持久化。
- Demo 启动脚本在服务启动前调用现有 `db-upgrade`，支持 `data` 目录下隔离数据库并使用配置端口；自检脚本现在比较实际数据库 schema 与迁移 head，而非只打印代码 head。
- 更新了对应的桌面和移动端九页验收截图。截图用例等待对应页面的主要内容、异步数据和路由懒加载完成后再保存，避免把加载占位误当成最终页面。
- 来源 PDF 指纹变化后，不允许再基于旧的来源核验新增已采纳结构化复核或确认新教师案例；为两条路径补充回归测试，避免记录先被写成正式状态、之后才由发布预检发现来源已过期。
- 符号链接安全回归测试原先依赖 Windows 创建符号链接权限，在本机被跳过；改为仅对目标路径注入链接解析结果/链接属性，仍经过实际迁移与来源读取拒绝逻辑，从而可跨平台运行。
- 班级诊断服务额外拒绝旧快照中标记为有效、但分值为 `NaN` 或无穷大的作答，避免非有限数污染班级分数和比例；新增异常快照回归测试。
- 学生洞察同样拒绝非有限逐点评分分值和最大分，避免异常旧快照生成学生事实或跨题问题归纳；新增异常评分点回归测试。
- 模拟学生缺少班级编号时，分析导入现在明确拒绝，而不是把空字符串计作一个班级，避免污染班级汇总；用空白班级 CSV 数据新增回归测试。
- Playwright 临时数据清理器的符号链接拒绝用例不再依赖 Windows 链接权限，通过注入链接元数据稳定验证“拒绝删除并保留外部数据”。
- 案例建议也会对历史运行中的空班级编号名单关闭候选生成，避免旧快照再次展示空班级或形成错误的班级覆盖说明。
- 赛事发布预检现在校验运行名单中的学生编号唯一且非空、班级编号非空；旧运行若名单不完整，会阻断案例选择与正式导出，不再只验证所选案例 ID 存在。
