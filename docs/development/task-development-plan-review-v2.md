## 4. 关键策略最终结论

### TASK02 版本选择

官方规定事件 ID 用学生—节点—题目表示，版本从1起，每次重新提交/改分递增；官方没有规定坏版本或同版本重复的回退处理。因此项目建议在 Phase 0 签核以下唯一规则：

1. 先验证事件身份字段一致、事件号与组成字段相符、版本是唯一正整数序列。
2. 同一事件出现任意重复版本号、事件身份冲突或无法判定版本顺序，隔离整事件并保留所有源行。
3. 否则选择数值最高版本，再校验引用、状态、分数、满分等内容。
4. 最高版本若内容非法，隔离整事件；绝不回退到旧版本。
5. 最高版本为待评分/未作答时作为当前状态分别计数，不进入得分分母。
6. 唯一最高版本有效时，低版本内容异常只产生审计finding，不阻断新版本；旧版仍保留且不重复计分。

该策略把“版本顺序”与“记录内容是否合法”分开，消除了原规划含混处。它是项目异常处理建议，不是赛事额外规定。

### TASK02 统计与评分点

得分率 = 同一过滤范围内有效已评分事件得分总和 S ÷ 这些事件满分总和 M；M=0时输出 null/unknown。待评分、未作答、无记录和异常事件都不进分子/分母；合法已评分0分进分母但得分为0。班级按总分/总满分加权，不能平均学生百分比。节点默认分开统计，N01/N02差异不是学习进步。

当前没有逐学生实际分配题目表，故“应测数量”不可计算。题目覆盖和指标覆盖只能称“记录/评分证据覆盖”，不能叫应测完成率或掌握率。

评分点来自题目评分点文本和作答记录评分点得分文本，可在编号、分值、总分核验一致时逐点求和。步骤没有显式外键，自动只能呈现原文、分数和评分点结果；具体错误步骤/概念诊断需人工核验。公开数据总分与评分点不一致时，按项目建议保留通过总分校验的总分、排除该行的评分点聚合并告警。

### TASK03 推荐策略

最终为八条规则：范围未教学、无有效记录、待评分、未作答/缺记录、单题部分失分、多个题出现经人工映射的重复表现、有限范围内多题满分、证据冲突/资源不足。无0.6或其他得分率分界，不增加掌握等级或推荐分。TR-06/07要求至少两道不同题的门槛只是项目防止单题过度推断的证据下限，需Phase 0签核，不是赛事规定或掌握等级。明确的题目事实可以输出；对具体误解的结论必须有评分点映射证据，否则请求教师观察。资源按人工核验指标/材料映射选取，没有已核来源时降级，不以第一道同指标题替代材料。
