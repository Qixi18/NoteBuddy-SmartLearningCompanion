## 四、五分钟问答备稿

1. **为什么两班不能简单排名？** 先核对共同题、参与学生、有效记录和分母；覆盖不等时描述差异并说明限制，不下总体优劣结论。
2. **无记录是否代表学生不会？** 不是。记录不足和错误表现分开；无记录只触发补充任务或观察，不产生未掌握标签。
3. **推荐为什么可信？** 每条结论回到当前学生/节点/材料/来源行；材料先过白名单与来源签核，教师保留最终修改权。
4. **模型错了怎么办？** 统计使用确定性程序；模型仅作草稿且引用需受限校验，最终建议由教师审核。没有真实 API 和教师审核的证据时明确说明未验证。
5. **如何验证教学有效？** 本数据只支持核对分析与建议依据，不足以证明真实教学成效；需后续合规试点设计和可比性确认。
6. **新增数据如何确认？** 比对文件哈希、字段和运行版本，重新导入和预检；旧教师签核和发布指纹不自动沿用。
